# WebMend

An AI-powered web accessibility auditing and auto-remediation system.

## Tagline

Find. Fix. Verify.

## Overview

WebMend identifies web accessibility issues, recommends
appropriate fixes, applies approved changes, and verifies
improvements through automated re-auditing.

## Technology Stack

- Python
- Playwright
- axe-core
- LangChain
- LangGraph
- Streamlit
